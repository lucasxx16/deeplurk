# Sanitization and scope

This staging tree was built by an explicit allowlist rather than copying a project directory or its history. It excludes model weights, virtual environments, original chats, personal account details, private endpoints, profiles, credentials, raw experiment logs, notebooks, archives, images, and source datasets. A fictional schema sample is retained. Source materials were not altered. The browsing template has been adjusted to use portable placeholders.

Before any upload, inspect every file, scan for secrets and personal identifiers, and independently confirm the destination and privacy setting. Regex scans cannot guarantee absence of sensitive content or establish redistribution rights. Project materials are shared without a new license grant; assess rights before making the repository public.
