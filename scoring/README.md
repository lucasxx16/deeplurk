# Experimental SRM scoring adaptation

`calibration_adapter.py` and the selected GPU computation functions in `runtime.py` are adapted from the actual canonical-v4 protocol and batch worker. `score.py` is a new single-input entry point; it has not been run with the 14B model in this portable form. It expects locally obtained original weights and the exact upstream `inference.py` template and checks the latter's SHA-256. The upstream template and weights are not bundled; check their own licenses and supply them separately. Exact chunked attention/device scheduling is hardware- and version-dependent. Never infer that CPU-only 32 GB is sufficient.

The input JSON has `context` and `hypothesis` fields. Run with a compatible environment, `python scoring/score.py --model-dir PATH --template PATH --input PATH`. Output contains raw axes, RINo novelty probabilities, their expected score, and `q=2*expectation-1`. Probability of being true is the scientist rating dimension for a hypothesis's likelihood of being true, distinct from feasibility; SRM learns ratings and preferences on this dimension, but its raw reward is not a calibrated 0–1 probability, a direct 1–9 prediction or success rate, and this batch is not a direct expert rating. The novelty mapping is rubric rescaling. The original fit is preserved byte-for-byte; its SHA-256 is `9a7e0df7c709c4c75477ad6fe5101225a880231c4759410211d4f96efce6fea2`. Its training CV is selection evidence, not independent validation. Other axes remain uncalibrated. See [Bao et al., sections B.2 and A.11](https://arxiv.org/html/2606.08251v1).

The original environment used Python 3.11, torch 2.7.0+cu128, transformers 4.57.3, accelerate 1.12.0, bitsandbytes 0.50.2, numpy 1.26.4 and scipy 1.17.1. Install hardware-compatible builds separately. Before use, compare tokenization, short-input standard versus blocked attention and repeated raw scores on the target device; audit model files and revision. The new wrapper omits historical batch checkpoint and integrity guards and is not production-ready.
